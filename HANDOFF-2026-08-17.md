## PUI-BC-026 — Sparse species profile incorrectly clears pair evidence

状态：**regression_verified**（#531）。

### 发现

Evidence Batch 1 初始版本给孔雀鱼新增 reviewed profile 后，在没有新增 pair rule 的情况下，孔雀鱼 ↔ 红绿灯/宝莲灯 4 个方向从 `insufficient_data` 被提升为 `caution`。根因是稀疏 species profile 中“未记录 predatory / territorial 风险”被错误解释成 pair-level “行为资料已审核无阻断”。

### 正确边界

- reviewed species profile 可支持明确 species-level 阻断；
- profile 未记录某类风险 **不等于** 已证明 pair 中不存在该风险；
- 没有 reviewed pair rule 时，只要没有更高优先级 hard block，authoritative product decision 必须继续 `insufficient_data`；
- hard block 优先级高于 missing pair evidence，因此像白云金丝 → 孔雀鱼若存在明确阻断，可正确返回 `not_recommended`；
- explicit reviewed pair rule 仍可产生 `compatible / caution / not_recommended`。

### 修复

`src/modules/knowledge/compatibilityKnowledge.ts` 在 authoritative `evaluateCompatibilityDecision` 边界加入 `pair_evidence_unreviewed`：双方有 reviewed profile、没有 reviewed pair rule、且不存在更高优先级 hard block 时，补 medium missing-data 并保持 `insufficient_data`。

`test:compatibility-evidence-coverage` 同时锁定：

- 红绿灯 ↔ 宝莲灯 explicit reviewed pair 继续双向 `caution`；
- 孔雀鱼 → 红绿灯为 `insufficient_data + pair_evidence_unreviewed`；
- 两个 reviewed species profile 没有 pair rule 时不得自动进入 `compatible/caution`；
- hard block 可直接 `not_recommended`，不强制降级为 `insufficient_data`；
- recordable pair 不允许残留 high/medium unresolved missing-data；
- Batch 1 的 priority recordable directions 必须继续 **2**。
