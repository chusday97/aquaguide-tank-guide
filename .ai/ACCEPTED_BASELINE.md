# Accepted Baseline

## Accepted business behavior

- `origin/main` is the code fact source.
- “查看当前鱼缸风险” expands in the current species detail without changing the URL.
- Only “加入混养比较” navigates to the independent `/compatibility` page.
- Existing `ThreeAquarium` behavior and its single Canvas remain authoritative.

## Visual status

No full React visual baseline is currently accepted. 4196/4197 are reference inputs only until the combined HTML Freeze is accepted.

## Acceptance rule

An HTML block is accepted only when its structure, action, responsive state and Owner mapping are recorded. Any change reopens that block for review.
