# Product Rules

- Four core entries: Aquarium, Encyclopedia, Care and Collection.
- Compatibility is an independent page, not a third Encyclopedia mode.
- One external page header per page; title and long description stay outside media.
- Interactive Encyclopedia flow: scene species → base species/variant selection → detail surface.
- Interactive Care flow: water/livestock/filter → problem cards → guide detail → user-started task.
- Desktop details occupy a page Rail; mobile uses one Sheet. Only one primary auxiliary surface may be open.
- Aquarium keeps one real 3D Canvas; stage actions and text do not cover the Canvas.
- Visual decisions must be accepted in HTML before React implementation.
