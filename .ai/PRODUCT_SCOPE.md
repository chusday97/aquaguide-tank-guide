# Aqua Product Recovery Scope

Updated: 2026-09-11
Branch: product-recovery-20260911

## Current product goal
Recover Aqua around one core promise: Aqua knows the user's tank and tells them what to do next.

## P0 — Stability and recovery
- Single active product branch: `product-recovery-20260911`
- Freeze unrelated UI
- Treat legacy `feature/admin-content-v0` as reference only
- Establish regression/golden-case protection before broad UI work

## P1 — Core product capability
1. Action Layer / beginner result mode
   - final decision first
   - one primary reason
   - one next action
   - optional "why" and evidence details
2. Compatibility V2
   - hard biological constraints
   - soft husbandry guidelines
   - context-dependent capacity/stability risks
   - explicit unknown / insufficient-information state
3. Species Knowledge V2
   - sex identification
   - reproductive mode/state
   - social/group requirements
   - adult size and spatial needs
   - behavior/predation/territorial traits

## P2 — Trust and evidence
- Deeply curate 30–50 common species first
- Field-level provenance and confidence
- Real-world tank stability can adjust only soft constraints
- Golden compatibility cases and regression tests

## Out of scope until P1 is stable
- Admin redesign
- SEO workflow expansion
- broad visual redesign
- new unrelated product modules
- mass expansion to every species before the core 30–50 are trustworthy
