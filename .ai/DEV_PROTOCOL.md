# AI Development Protocol

## Purpose
Maintain continuous engineering execution across AI sessions.

## Workflow
1. Read current goal, live status, handoff and progress before changes.
2. Diagnose using evidence before modifying code.
3. Execute changes, validate, and record results.
4. Keep local, GitHub, Preview and Production states aligned.

## Priority
P0 Production blockers
P1 Core user flows
P2 UX improvements
P3 Optimization

## Source of Truth
1. Code
2. Tests
3. Project documents
4. Execution logs

## Required Records
Every meaningful change updates:
- EXECUTION_LOG.md
- CHANGELOG_AI.md
- DECISION_LOG.md
