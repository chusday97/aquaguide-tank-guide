## 首轮范围

- 目标：5–8 名正在准备第一个鱼缸或刚开始养鱼的真实参与者。
- 核心任务：首次完整鱼缸适配、只完成物种识别、从识别进入当前鱼缸适配。
- 隐私：不记录姓名、邮箱、鱼缸名、图片、自由诊断描述或账号 ID。
- 原始匿名记录默认保存在 Git 忽略的本地文件，仓库只提交模板和聚合结果。

## 汇总门禁

- 没有记录时只输出固定提示，不输出 0% 或 100%。
- 有记录时才计算任务完成率、中位时间、中位点击数、首次误点、放弃位置和高频问题标签。
- 用户原话只保留已脱敏且与价值理解直接相关的片段。
