# AquaGuide AI Evaluation 状态

> 更新日期：2026-08-01。

## 当前已有证据

| 能力 | 当前证据 | 能说明什么 | 不能说明什么 |
| --- | --- | --- | --- |
| AI 建缸助手 | 20 个程序化场景 | 契约、候选约束、失败降级和问题数量边界 | 真实模型在开放表达下的整体质量 |
| 每日检查 | 本地规则与 Provider 异常场景 | 风险不可降低、文章白名单和本地兜底 | 真实用户自由描述覆盖率 |
| 物种状态判断 | 14 个规则/流程场景 | 红旗优先、最多三问、双语规则一致性 | 疾病诊断准确率；本产品也不提供确诊 |
| 视觉识别 | 流程与未配置兜底 | 用户可确认候选、失败可转手动搜索 | 真实图片识别准确率 |

## 本轮目标

- 把硬编码场景迁移为可审阅的版本化 JSONL。
- 分离 deterministic、mocked provider 与显式开启的 live provider。
- 统一输出结构、安全、规则、降级、本地化与分类指标。
- 建立 Badcase → 修复 → Regression 的可追溯闭环。

## 发布边界

- Mock 结果不得称为真实模型质量。
- Live Eval 未设置 `RUN_LIVE_EVAL=1` 时必须跳过，不调用付费模型。
- 报告不得包含自由描述、图片 Base64、密钥或完整模型原文。
- 视觉 manifest 在获得经授权的真实照片前保持未完成状态。
